6. AUTHENTICATION & SECURITY
--------------------------------------------------------------------------------
Auth Protocol:        Passwordless Email OTP Authentication (6-digit one-time passcodes)
Password Encryption:  bcryptjs 2.4.3
Token Security:       JSON Web Tokens (jsonwebtoken 9.0.2)
Evidence Chain:       SHA-256 Cryptographic Checksums (Tamper-evident chain of custody)
Role-Based Access:    Strict Partitioning across 6 Specialized Portals:
                      1. /citizen    - Grievance intake, CNR tracking, advocate lookup
                      2. /advocate   - Case briefs, Vakalatnama filing, precedent search
                      3. /police     - Crime narrative dictation, BNS suggestions, evidence
                      4. /registrar  - Document scrutiny queue, CNR number generator
                      5. /judge      - Precedent analysis, interim relief, order drafting
                      6. /admin      - Telemetry, cluster health, immutable audit logs
